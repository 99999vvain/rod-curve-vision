弯曲刚度标定

将鱼竿水平夹持，在竿梢直接悬挂已知质量。测量夹具出口中心到加载后梢端的竖直落差，以向下为正。校准计入杆身自重。挂重质量包含吊钩与容器。

B₀ 指第一节元端单管的等效弯曲刚度。可输入独立测得的 B₀。若已有接头转动刚度，打开「计入接头附加柔度」后会将其用于标定。

四节竿可在导入实验 CSV 后同时反算 B₀ 和 B₄。也可手动填写 B₄。B₄ 留空时各节按同一等效模量计算。若使用梢端落差标定，已填的 B₄ 会作为固定值。

力学公式与计算方法

以夹具出口为原点，弧长 s 从根部指向竿梢。x 向右，y 向上，切线角 θ 逆时针为正。模型采用初始直杆，允许大转角，忽略轴向伸长和剪切变形。

A = π(D² − d²)/4，I = π(D⁴ − d⁴)/64，d = max(0, D − 2t)。

每节线质量 μᵢ = mᵢAᵢ / ∫ Aᵢ ds，q = g Σ μᵢ。搭接处两节质量都计入；夹具内部不计入自由段重力。

Bnom(s) = Σ Eᵢ Iᵢ(s)，E₁ = E₂ = E₃ = B₀/I₀。四节竿填写 B₄ 时，E₄ = B₄/I₄,元端。未单独填写的杆节取 Eᵢ = B₀/I₀。

I₀ 为第一节元端的截面惯性矩。搭接区对两根管的弯曲刚度求和。若已知接头的转动刚度 K，再计入附加柔度 1/B = 1/Bnom + 1/(Kaⱼ)。

Rx = P sin β，Ry(s) = −P cos β − ∫sL q(u) du，P = mg。

x′ = cos θ，y′ = sin θ，θ′ = M/B，M′ = Rx sin θ − Ry cos θ。边界为 x(0) = y(0) = 0、θ(0) = α、M(L) = 0。

从杆节和搭接边界划分网格，以节点转角为未知量。先施加自重，再逐级增大端载，用总势能的驻值方程求转角，最后累加各段的坐标增量。

节内等效模量取常数，质量按截面积分配。刚度标定和曲线验证应使用不同加载工况。
