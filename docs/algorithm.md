# 识别算法

输入是一张侧视照片和 2–4 个人工参照点，输出是沿竿身的中心线采样点（弧长 `s`、夹具出口相对坐标 `x,y`、原图像素坐标 `u,v`、局部图像证据、复核标记）。全部计算在本机完成。

## 1. 为什么不能直接用边缘检测

鱼竿在照片里同时存在两种完全不同的外观：

| 部位 | 外观 | 宽度 |
|---|---|---|
| 把手到中节 | 涂装黄色，饱和度中等 | 10–25 px |
| 细梢 | 裸露碳布，接近黑色 | 1–3 px |

Canny 之类的边缘算子会在涂装段给出两条平行边、在细梢段给出噪声；轮廓提取会把旁边任何同色物体（幕布、水桶、墙面）连进来。因此本程序不做全局分割，而是**沿人工给定的参照点之间做局部条带搜索**：把"杆在哪里"这个全局问题降维成"在一条窄带里找一条连续路径"。

## 2. 证据场

对条带上每个像素计算两路证据，取较大值：

**涂装段（黄色内部）**
先用 HSV 阈值取黄色掩膜，再对掩膜做欧氏距离变换。得分

```
body = [yellow] · (0.55 + 0.45 · min(depth / 6, 1))
```

`depth` 是该像素到最近非黄色像素的距离。这个"离边界多远"的权重是关键：一片大面积黄色（墙面、箱子）内部得分同样接近 1，但它只有一小块落在窄带里，无法形成贯穿整条带的连续路径；而杆身是窄带里贯穿始终的黄色条，路径搜索自然会选它。

**细梢段（暗线）**
对灰度图做高斯平滑后，在 ±2、±4、±7、±11 px 四个尺度上比较中心与两侧：

```
contrast(x) = max_r [ min(grey(x-r), grey(x+r)) − grey(x) ]
line = 0.88 · clamp((contrast − 3) / 24, 0, 1)
```

取两侧的**较小值**而不是平均，是为了让单侧陡边（幕布褶皱、阴影边界）得低分：真正的细杆两侧都亮，单侧边界只有一侧亮。

## 3. 条带重采样

相邻两个参照点确定一条弦，弦长 `d`，法向为 `n`。沿弦等距取 `ceil(d / 2) + 1` 行，每行沿 `n` 取半宽

```
half_width = max(16 px, 0.16 · d)
```

个采样点，用 `cv2.remap` 一次性把这条弯曲的窄带拉直成一张矩形图。之后所有运算都在直条带上做：行 = 沿杆进度，列 = 横向偏移。

搜索半宽取弦长的 16%，是因为杆在两个参照点之间最多偏离弦这么多；它随弦长自适应，短段不会被背景挤满，长段不会把杆挤出窗口。

## 4. 路径搜索（动态规划）

在条带上找一条从首行中点出发、到末行中点结束的路径，每行只能横移 `±3` 个采样点（即切线与弦的夹角不超过约 56°），代价为

```
cost(row, col) = −evidence + 0.055·(shift/3)² + 0.025·(offset/half_width)²
```

后两项是弱先验：偏好小横向速度和靠近弦中心，避免路径在等强度区域乱飘。用动态规划求全局最优，复杂度 `O(行 × 列 × 移位数)`，4096 px 图上单段约 0.05 s。

另有一个可选的二阶项（`--curvature-penalty`），惩罚相邻两行横向移动量的变化。实测它在部分工况能压掉伪折角，在另一些工况会让路径滞后于真实弯曲，因此**默认关闭**，见 [validation.md](validation.md)。

## 5. 截面中点修正

路径搜索选的是"证据最强的像素"，在一条 20 px 宽的杆上，它可能贴在某条边上，产生半个杆宽的系统偏差。所以每行再做一次一维剖面分析：

1. 在以追踪点为中心、半径 16 px 的窗口里，若附近有黄色像素，就取包含它的黄色连通段两端的中点；
2. 否则取窗口灰度最低点作为种子，以两侧亮度的 80 分位为基线，取低于 `基线 − 0.42·对比度` 的暗带两端中点；
3. 若修正量与追踪点相差超过 7 px，判定为误吸附，保留原位置。

这一步把系统偏差压到亚像素量级，也是合成测试能做到 0.8 px 均方根误差的原因。

## 6. 样条与等弧长重采样

分段追踪得到的点列在参照点处可能有折角。用参数样条（`scipy.interpolate.make_splprep`，三次）拟合，权重 = `0.35 + 0.65·evidence`，并把参照点的权重设为 100——照片里唯一可信的位置就是人手点的这两个点。

样条先在 4 倍密度上求值再累加弧长，减少像素网格带来的长度偏差；最后按固定弧长间隔（默认 4 px）重采样，使输出的 `s` 是等间距的，便于和力学模型按弧长对齐。

## 7. 复核标记

两个条件任一成立即标橙点：

- 该点图像证据 < 0.16（杆身被遮挡、离焦或与背景同色）；
- 样条结果与追踪点偏离超过 `max(2.5 px, 3×平滑参数)`（说明这段的原始追踪本身不连续）。

橙点不是错误，而是"这里需要人看一眼"。它同时体现在 CSV 的 `needs_review` 列和模型的误差统计里（`reviewCount`）。

## 8. 从像素到毫米

三种互斥方式，优先级由调用方决定：

| 方式 | 输入 | 适用 |
|---|---|---|
| 已知弧长 | 夹具出口到竿梢的实测弧长 | 正侧拍、相机水平 |
| 均匀比例 | mm/px | 已知参照物尺寸 |
| 平面标定 | ≥4 组 `image_px ↔ world_mm` | 有同平面参照、存在透视 |

前两种用统一比例 `实测总长 / 提取总弧长`。第三种用单应矩阵把整条曲线投到物平面，弧长沿投影后的曲线重新累积——这也是唯一能同时给出**世界坐标下夹持角**的方式。

y 轴在输出时翻转，使 `y` 向上、`x` 由夹具出口指向竿梢；这与力学模型的坐标系一致，模型可以直接读 CSV 而不需要再变换。
