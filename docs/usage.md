# 使用说明

三种入口共用同一套追踪代码（`rodcurve/`）：浏览器界面、命令行、Tkinter 桌面窗口。

## 0. 安装

需要 Python 3.10 或更新版本（开发与测试用的是 3.13）。

```bash
python -m pip install -r requirements.txt
```

`matplotlib` 只在画曲线图和打开点选窗口时用到；只做批量提取的话可以不装。

## 1. 浏览器界面（推荐）

```bash
python -m rodcurve.server
# 或启动时直接载入照片
python -m rodcurve.server examples/sample-rod-57g.jpg
```

浏览器会自动打开 `http://127.0.0.1:8765/`。两个页面：

- **图像识别**：导入照片 → 从夹具出口开始依次点参照点（左键加点、右键撤销、滚轮缩放、`拖动平移` 后再点一次回到选点）→ 填自由段实测弧长（mm）→ `提取曲线` → 可切换`变形曲线`查看、`导出实测 CSV`；
- **力学预测**：设置竿型、端载、夹持角 → 查看预测曲线与实测曲线的误差 → 可`导入实验 CSV` 或直接`送入模型对照` → 四节竿可`反算 B₀ 和 B₄`。

`测量夹持角`：先点靠竿柄侧、再点靠竿梢侧，紫线即测量方向；夹具挡住竿身时可沿与夹持段平行的参照边点选。

照片和计算结果只在本机处理，服务只监听 `127.0.0.1`。

## 2. 命令行

```bash
# 交互选点（弹出 matplotlib 窗口，可顺手填长度）
python -m rodcurve photo.jpg

# 直接给点：按夹具出口 → 引导点 → 竿梢的顺序，可重复 --point
python -m rodcurve photo.jpg \
  --point 3781,463 --point 1908,647 --point 344,1491 \
  --length-mm 3350 --clamp-back 3900,455
```

常用参数：

| 参数 | 作用 | 默认 |
|---|---|---|
| `--corridor` | 搜索半宽占弦长的比例 | 0.16 |
| `--smoothing-px` | 样条平滑量 | 0.75 |
| `--spacing-px` | 输出采样间距 | 4.0 |
| `--curvature-penalty` | 路径二阶平滑惩罚，0 为关闭 | 0 |
| `--length-mm` | 夹具出口到竿梢的实测弧长 | — |
| `--mm-per-px` | 均匀比例 | — |
| `--calibration` | 平面标定 JSON（与上面两项互斥） | — |
| `--clamp-back` / `--clamp-front` | 夹持段两点，用于算夹持角 | 后者默认取夹具出口 |
| `--no-plot` | 跳过 `curve.png` | 关闭 |
| `--overlay-compress` | 叠加图 PNG 压缩级别 | 6 |

输出到 `outputs/<照片名>/`（同名重复运行会加编号）：

| 文件 | 内容 |
|---|---|
| `centerline.csv` | 每行一个采样点，见下 |
| `overlay.png` | 青色拟合线、橙色复核点、ROOT/TIP 标记、紫色夹持段 |
| `curve.png` | 等式纵横比的变形曲线，标注梢端到夹具水平面的距离 |
| `measurement.json` | 参照点、弧长、梢端坐标、复核点数、标定方式 |

## 3. 批量

`cases.csv`（可直接用 Excel 编辑后另存为 CSV）：

```csv
image,points,length_mm,clamp_back
photos/28-3450-0g.jpg,"3781,463;1908,647;344,1491",3350,"3900,455"
photos/28-3450-57g.jpg,"3781,463;1908,647;344,1491",3350,"3900,455"
```

```bash
python -m rodcurve --cases cases.csv --jobs 4 --no-plot
```

- `points` 用 `;` 分隔多个点、`u,v` 表示一个点，顺序与 `--point` 一致；
- **`points` 里有逗号，在 CSV 中必须用双引号包裹整格**，否则会被拆成多列（程序会检查列数并报错提示）；
- `clamp_back` / `clamp_front` 含逗号，同样要用引号包裹；可省略；
- 汇总写到 `outputs/summary.csv`，含每张的弧长、梢端毫米坐标、夹持角、复核点数。

## 4. 桌面窗口

```bash
python tools/rod_curve_gui.py
```

功能与浏览器版相同，适合不想开浏览器或需要离线演示的场合。

## 5. 平面标定文件

同平面内有已知尺寸的参照物时（如贴纸网格、地面砖），用它替代"已知弧长"：

```json
{
  "image_px": [[150, 100], [1100, 100], [1100, 650], [150, 650]],
  "world_mm": [[0, 500], [1000, 500], [1000, 0], [0, 0]],
  "note": "四个点的顺序必须一一对应；world 的 x/y 方向要与力学模型一致"
}
```

至少四点、不能重复、不能共线。程序会输出标定残差的 RMSE，并在投影不连续时直接报错而不是给一个错误结果。

## 6. CSV 列

| 列 | 含义 |
|---|---|
| `s_px` | 从夹具出口起算的弧长（像素） |
| `x_px`, `y_px` | 相对夹具出口的坐标，`y` 向上为正 |
| `image_u_px`, `image_v_px` | 原图像素坐标（左上角为原点，`v` 向下） |
| `evidence` | 该点局部图像证据，0–1 |
| `needs_review` | 1 表示建议人工复核 |
| `s_mm`, `x_mm`, `y_mm` | 有标定时出现 |
| `clamp_angle_deg` | 测了夹持角时出现，每行相同 |

## 7. 常见问题

**提取失败，提示"请加一个沿竿身的引导点"。**
两个参照点之间杆的弯曲超出了搜索半宽，或这段被完全遮挡。在弯曲最大的位置补一个引导点。

**曲线在某段明显偏离杆身。**
看该处是否有橙点。有橙点说明程序自己也不确定，补引导点重跑；没有橙点而确实偏了，说明那段有更强的同向结构（幕布褶皱、边线），同样补引导点。

**竿梢被细线或挂重挡住。**
把竿梢参照点放在线挡不到的那一侧，或用 `--spacing-px 2` 提高采样密度后人工看 CSV。

**送入模型失败，提示需要毫米坐标。**
先填自由段实测弧长（`--length-mm` 或界面里的输入框）再提取。像素坐标没有物理意义，模型拒绝接收。
