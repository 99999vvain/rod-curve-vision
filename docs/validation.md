# 精度与验证记录

本文件记录可复现的量化结果。所有命令都在仓库根目录执行。

## 1. 合成真值（绝对精度）

`tests/test_tracing.py` 用一张合成照片检验绝对精度：4096 × 3072 画布，杆身从 22 px 线性收细到 7 px，之后接一段 2 px 的碳布细梢，中心线为已知抛物线。

```bash
python -m pytest tests -q
```

| 指标 | 数值 |
|---|---|
| 均方根误差 | 0.81 px |
| 95 分位误差 | 1.44 px |
| 最大误差 | 2.8 px（出现在夹具出口附近前 8% 弧长） |
| 弧长 3 500 px 上的相对误差 | 约 0.02% |

误差集中在涂装段转细梢的过渡处和起点附近：前者杆宽从 7 px 突降到 2 px，截面中点本身只有 1 个像素的判别余量；后者受端点固定约束影响。

## 2. 与原始实验记录的回归比对

`tools/validate_against_reference.py` 把当前实现与当初产出实验数据的记录逐点比较。**这是回归检验，不是精度检验**——参照曲线来自同一方法的早期版本。参照点未存盘，脚本从参照曲线自身取首点、中点、末点作为参照点，因此差异里也包含参照点选择的不同。

```bash
python tools/validate_against_reference.py examples
```

| 照片 | 参照弧长 / px | 本程序弧长 / px | 中位偏差 / px | RMS / px | P95 / px | 最大 / px | 复核点 |
|---|---|---|---|---|---|---|---|
| sample-rod-0g.jpg | 3543.8 | 3543.9 | 0.18 | 0.26 | 0.46 | 0.91 | 19/887 |
| sample-rod-57g.jpg | 3765.8 | 3765.6 | 0.19 | 0.44 | 0.78 | 2.05 | 20/943 |

在完整实验数据集（6 组可配对工况，4096 × 3072 原图）上重复过同一比对，中位偏差 0.16–0.25 px，最大偏差 0.6–14.7 px，最大偏差出现在被竖挂线遮挡的梢端附近，那些位置同时被标为复核点。

## 3. 曲率正则的取舍

`--curvature-penalty` 在路径搜索中加入二阶平滑项。在 6 组数据上测得的效应并不一致：

| 工况 | 默认（0）RMS / 最大 | 0.05 RMS / 最大 |
|---|---|---|
| 28 3450 0 g | 0.18 / 0.58 px | 0.15 / 0.34 px |
| 28 3450 35.8 g | 2.32 / 7.17 px | 2.60 / 7.28 px |
| 37 3437 52.3 g | 1.55 / 8.24 px | 2.60 / 14.73 px |

结论：它对「压制折角」有效，但代价是让路径在强弯曲段滞后，净收益不稳定。因此**默认取 0**，并把一阶搜索保留为快速路径（0.19 s 对 0.6 s）。这条参数留在这里是给「背景中有强线性干扰」的场合用的，默认不开。

## 4. 耗时

4096 × 3072、12 MP 照片，单张：

| 阶段 | 耗时 |
|---|---|
| 导入 numpy / OpenCV / SciPy | 0.68 s |
| 解码 JPEG | 0.12 s |
| 中心线提取（3 段共约 1 870 行条带） | 0.19 s |
| 叠加图绘制 | 0.01 s |
| 叠加图 PNG 写盘（压缩级别 6） | 1.06 s |
| 叠加图 PNG 写盘（压缩级别 1） | 0.37 s |
| 曲线图 matplotlib（首次含导入） | 0.40 s |
| **合计（含绘图）** | **约 2.5–3.5 s** |

真正的计算只占 0.19 s，其余是解码与写盘。叠加图是 12 MP 的 PNG，压缩级别从 6 降到 1 可省约 0.69 s，代价是文件从 11.5 MB 涨到 18.6 MB。批量处理时用 `--overlay-compress 1` 或直接跳过绘图更划算。

批量实测（6 张 4096 × 3072，`--no-plot`，跳过绘图）：

| 方式 | 墙钟时间 |
|---|---|
| `--jobs 1` | 9.7 s |
| `--jobs 4` | 6.1 s |

只有 1.6 倍而不是 4 倍，因为单张的真正计算只有 0.19 s，其余是进程启动（每个子进程要重新导入 OpenCV/SciPy）、JPEG 解码和 PNG 写盘。批量并行的收益主要在"张数多"，不在"每张快"。

## 5. 已知局限

1. **真实照片没有真值。** 只有合成图能给出绝对误差；对实拍照片，本程序能保证的是与实验记录一致（第 2 节），不是"比实测更准"。
2. **单平面假设。** 所有标定都假设杆在垂直于光轴的平面内弯曲。相机明显俯仰时，弧长会系统性偏短，此时必须用平面标定（`--calibration`）。
3. **细梢的可分辨极限。** 杆宽低于约 1.5 px 时，截面中点退化为整像素，此时精度由像素量化决定（约 ±0.5 px，折合 3 450 mm 自由段上约 ±4 mm）。
4. **遮挡与同色背景。** 杆被竖挂线、支架遮挡，或与背景同色（例如黄色杆贴在黄色墙面）时，路径可能沿错误结构行进。程序会用橙点标出可疑位置，但不会自动修正——需要人工加引导点重跑。
5. **复核点比例不固定。** 6 组实验工况实测为 0.7%–6.7%（6/894 到 60/896），比例最高的一组（37 3437 52.3 g）同时也是与参照曲线偏差最大的一组（14.7 px），两者一致指向该组照片的梢端成像质量。复核比例超过 5% 时应视为该组数据需要人工核对或重拍。
