# 力学模型

力学部分在 `rodcurve/webui/model.html` 中实现，是一个纯前端的求解器，可直接读取识别程序导出的 CSV。以下公式与该文件中的实现一一对应，符号沿用文件内的记号。

## 1. 基本假设

- 以夹具出口为原点，弧长 `s` 由根部指向竿梢，`x` 向右、`y` 向上、切线角 `θ` 逆时针为正；
- 初始为直杆，允许大转角，因此**不采用小转角近似**作为主算法（小转角解只作为对照曲线）；
- 忽略轴向伸长与剪切变形，横截面保持平面（Euler–Bernoulli 梁）；
- 竿身自重沿弧长分布，端部载荷为集中力。

这组假设对鱼竿是合理的：以 3.45 m、元径 12.8 mm 的样竿计算，长径比约 270，剪切变形可以忽略；但端载下梢端转角可达几十度，几何非线性必须保留。

## 2. 截面与刚度

对每一节，外径 `D`、内径 `d = max(0, D − 2t)`：

```
A = π(D² − d²)/4
I = π(D⁴ − d⁴)/64
```

线质量由该节实测质量反推：

```
μᵢ = mᵢ Aᵢ / ∫ Aᵢ ds
q  = g Σ μᵢ
```

搭接区内两节质量都计入；夹具内部的杆段不计入自由段重力。

名义弯曲刚度沿弧长叠加：

```
B_nom(s) = Σ Eᵢ Iᵢ(s)
```

三节及以内取统一的等效模量 `Eᵢ = B₀ / I₀`，其中 `I₀` 是第一节元端的截面惯性矩。四节竿可以给第四节单独一个元端刚度 `B₄`（`E₄ = B₄ / I₄元端`），因为细梢的等效模量常与粗节不同。

若已知接头转动刚度 `K`，搭接区按串联引入附加柔度：

```
1/B = 1/B_nom + 1/(K·aⱼ)
```

`aⱼ` 为该接头的搭接长度。接头是鱼竿刚度损失的主要来源之一，忽略它会让反算出的 `B₀` 偏高。

## 3. 平衡方程

端载 `P = mg`，与竖直向下成 `β` 角：

```
R_x = P sin β
R_y(s) = −P cos β − ∫ₛᴸ q du
```

几何与弯矩关系（`′` 表示对弧长求导）：

```
x′ = cos θ
y′ = sin θ
θ′ = M / B
M′ = R_x sin θ − R_y cos θ
```

边界条件：

```
x(0) = 0,  y(0) = 0,  θ(0) = α,  M(L) = 0
```

`α` 是夹持角，`L` 是自由段长度。`M(L) = 0` 表示竿梢为自由端。

弯曲应变（名义值，按外缘计算）：

```
ε = |M| / B · D / 2
```

代码中 `strain = |M/B| · D · 50`，单位是百分比（`×100`）并已含 `D/2`。

## 4. 求解方法

把杆离散成若干单元，未知量是节点转角 `θᵢ`。总势能

```
Π = Σ [ Bᵢ(Δθᵢ)²/(2hᵢ) − hᵢ( F_x cos θ̄ᵢ + (R_yᵢ − γ·Qᵢ) sin θ̄ᵢ ) ]
```

`θ̄` 是单元平均转角，`Qᵢ` 是该单元以下的累计自重，`γ` 为是否计入自重的开关。

驻值条件 `∂Π/∂θ = 0` 给出一个带状非线性方程组，用 **Newton 迭代 + 对角带状消元** 求解，配 Armijo 型线搜索；每次迭代后用根部力矩平衡

```
M(0) = x(L)·R_y − y(L)·R_x + Σ(自重对根部的力矩)
```

做独立校验，不通过就拒绝该解。

非线性较强时（大端载、大夹持角）单步 Newton 会发散，因此采用**载荷续算**：先只作用自重，求平衡；再以 18% 的步长逐级加端载到目标值，每级以上一级的解作为初值，失败则步长减半。续算保证的是「每一步都通过平衡校验」，而不是「任何参数组合都必然收敛」：步长减到 1/2048 仍失败时程序会明确报错并提示减小载荷或偏角，不会返回一个未收敛的解。示例工况覆盖 0–1000 g 与 ±75° 以内的夹持角。

## 5. 两条反算路径

**梢端落差标定 `B₀`**
水平夹持、竿梢挂已知质量，测夹具出口到加载后梢端的竖直落差。给定 `B₀` 求解一次得到落差，用对数二分（比值区间上二分）反求使落差等于实测值的 `B₀`。若已填 `B₄`，则固定它只反算 `B₀`。

**整条曲线反算 `B₀`、`B₄`**
以 `(ln B₀, ln B₄)` 为未知量，把实测中心线在共同弧长区间上等距取 161 个目标点（端点权重 `1/√2`），最小化二维残差平方和。用带 Levenberg 阻尼的 Gauss–Newton，雅可比由 ±0.005 的中心差分得到（前向失败时自动改后向）。多起点（中心点及其 ±ln3 偏移）避免落入局部极小。

反算后会给出**可辨识性判据**：雅可比矩阵归一化后两个方向的条件数不足时，提示"这条曲线不足以分辨 `B₀` 与 `B₄`"，而不是给一个看似精确实则不可信的结果。

## 6. 实验与预测的误差

两条曲线都是折线，若逐点做差会引入采样密度的影响。程序在共同弧长区间 `[lo, hi]` 上对两条折线分别线性插值，逐段解析积分平方误差：

```
RMSE² = Σᵢ (bᵢ − aᵢ) / (3(hi − lo)) · (dᵢ² + dᵢ·dᵢ₊₁ + dᵢ₊₁²)
```

这样得到的误差与采样密度无关，可以直接横向比较不同工况。同时给出竖直方向 RMSE、最大二维误差及其所在弧长、以及两条曲线各自末点的竖直差。

## 7. 与识别程序的接口

CSV 的列：

```
s_px, x_px, y_px, image_u_px, image_v_px, evidence, needs_review, s_mm, x_mm, y_mm, clamp_angle_deg
```

模型只读 `s_mm, x_mm, y_mm`（必需）与 `needs_review, clamp_angle_deg`（可选）。缺少毫米列时会明确报错并提示先填自由段长度——像素坐标不能直接进力学模型，因为弧长必须对应真实长度。
